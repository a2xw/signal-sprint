# Signal Sprint

A lightweight real-time two-player reaction game for the browser.

- Cross-device room creation and joining
- Brokered WebSocket multiplayer
- Shared round state and score tracking
- No backend account system required

**Repository:** https://github.com/a2xw/signal-sprint

When GitHub Pages is enabled for this repository, the app can be served at:

https://a2xw.github.io/signal-sprint/
